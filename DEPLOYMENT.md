# Solana Meme Coin Control Center

Production URL:
https://creiamo-uno-schema-di-agenti-per.vercel.app

Local dev:
```bash
npm run dev
```

Checks:
```bash
npm run check
```

Deploy:
```bash
npm run deploy
```

Notes:
- This is a paper-trading console.
- No wallet is connected.
- DexScreener data is fetched from public API endpoints in the browser.
- Paper portfolio and journal are stored in browser `localStorage` per domain.
